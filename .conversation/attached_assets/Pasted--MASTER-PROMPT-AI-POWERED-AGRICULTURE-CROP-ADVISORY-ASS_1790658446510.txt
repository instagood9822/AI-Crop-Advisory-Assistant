# 2. Core Mission Directive

Build a full-stack AI-powered agriculture advisory platform that helps farmers and agriculture students/users receive personalized crop recommendations and farming guidance based on agricultural conditions supplied through a structured form.

The application should collect relevant agricultural information such as:

* Location
* Soil type
* Soil pH
* Temperature
* Rainfall
* Humidity
* Available irrigation
* Season
* Land size
* Previous crop
* Farming objective
* Optional crop preference
* Additional observations

The system must send the validated information securely to the backend.

The backend must use Google's Gemini API through the official `@google/genai` SDK.

Gemini must generate structured agricultural recommendations rather than unrestricted conversational output.

The application must display the advisory in a clear, understandable dashboard.

Users must also be able to view their previous advisory records.

The system must prioritize:

1. Practical usefulness.
2. Data validation.
3. Explainability.
4. Safety.
5. Security.
6. Consistent AI output.
7. Responsive design.
8. Maintainable architecture.

The AI must never pretend that its recommendations are guaranteed agricultural outcomes.

For potentially harmful or high-stakes agricultural situations, the system should clearly recommend consultation with a qualified local agricultural expert.

# 3. Product Goal

Create a modern web application that acts as a digital agricultural assistant.

The core user journey is:

**Register/Login → Enter Farm Details → Validate Data → Generate AI Advisory → View Recommendations → Save Advisory → View History**

The advisory should help users understand:

* Which crops may be suitable.
* Why those crops may be suitable.
* Expected growing conditions.
* Basic cultivation considerations.
* Irrigation considerations.
* Nutrient/soil considerations.
* Potential pest/disease risks.
* General precautions.
* Recommended next steps.

The UI should be understandable to users with limited technical knowledge.

Avoid unnecessarily complex agricultural terminology.

When technical terminology is necessary, explain it in simple language.

# 7. User Flow

Implement the following complete flow.

## Step 1 — Landing Page

User visits `/`.

Display:

* Application name.
* Short description.
* Main CTA.
* Explanation of AI-assisted crop advisory.
* Feature overview.

User selects:

**Get Started**

If unauthenticated, redirect to `/login` or `/register`.

If authenticated, redirect to `/dashboard`.

## Step 2 — Registration

User enters:

* Email.
* Password.
* Password confirmation.

Validate client-side.

Submit to Supabase Auth.

After successful registration, establish session and redirect to dashboard.

## Step 3 — Login

User enters:

* Email.
* Password.

Authenticate with Supabase.

On success:

`/dashboard`

## Step 4 — Dashboard

Show:

* User greeting.
* Create Advisory button.
* Advisory statistics.
* Recent advisory cards.

## Step 5 — Farm Details

User opens:

`/advisory/new`

Complete the agriculture form.

Validate all required fields.

## Step 6 — Generate Advisory

Submit the form to the Express backend.

Backend:

1. Authenticate user.
2. Validate request with Zod.
3. Construct AI request.
4. Call Gemini.
5. Validate Gemini response.
6. Store advisory in PostgreSQL.
7. Return structured advisory.

## Step 7 — Display Advisory

Show:

* Recommended crops.
* Suitability.
* Explanation.
* Growing requirements.
* Water requirements.
* Soil considerations.
* Risks.
* Precautions.
* Next steps.

## Step 8 — History

User opens `/history`.

Display previous advisories.

## Step 9 — Advisory Detail

User opens `/advisory/:id`.

Display full advisory and original farm conditions.

## Step 10 — Delete

Allow users to delete only their own advisories.
